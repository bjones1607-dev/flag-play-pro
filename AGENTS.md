# Project rules

- FootballField separates player identifiers from optional route descriptions so clean diagrams retain receiver numbers and QB labels.
- The play builder saves through its existing storage flow before navigating to the print page so the latest drawing is available to print.
- Shared field-layout helpers define default QB positioning, bounded backfield dragging, and receiver labels excluding the center so diagrams and editing controls stay consistent.
- The play builder retains one center when changing player counts or assigning the center so a full formation has four numbered receivers plus C and QB.
